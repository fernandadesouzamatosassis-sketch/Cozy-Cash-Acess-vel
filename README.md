# Cozy Cash Acessível

 

## 📌 Sobre o projeto

O **Cozy Cash Acessível** é um aplicativo web de finanças pessoais desenvolvido com foco em **acessibilidade digital**, especialmente para **pessoas cegas**. 

O objetivo do projeto é permitir que o usuário organize suas finanças com **autonomia, segurança e privacidade**, utilizando leitores de tela e sem depender de elementos visuais.

 

Este projeto foi criado com foco em inclusão, inovação social e uso consciente de tecnologia.

 

---

 

## 🎯 Objetivo

Promover a **inclusão digital** por meio de um aplicativo financeiro que possa ser utilizado por pessoas cegas **sem necessidade de visão**, apenas com o apoio de leitores de tela.

 

---

 

## ♿ Acessibilidade

O aplicativo foi pensado desde o início com o princípio de **acessibilidade by design**, adotando boas práticas como:

 

- Interface simples, linear e baseada em texto 

- Compatibilidade com leitores de tela (NVDA, VoiceOver, TalkBack, entre outros) 

- Navegação possível apenas por teclado 

- Rótulos claros e descritivos para campos e botões 

- Feedback textual após ações importantes 

- Informações financeiras apresentadas em formato compreensível por áudio 

 

O aplicativo **não depende de gráficos ou informações exclusivamente visuais**.

 

---

 

## 💡 Funcionalidades

- Consulta de saldo

- Registro de despesas

- Registro de receitas

- Consulta de histórico financeiro

- Resumos financeiros em formato textual

 

---

 

## 🧪 Como utilizar

1. Acesse o link do aplicativo

2. Utilize um leitor de tela de sua preferência

3. Navegue pelo app utilizando teclado ou comandos do leitor

4. Execute as ações financeiras de forma autônoma
